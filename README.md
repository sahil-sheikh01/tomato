# Tomato 🍅

A modern food delivery website built with the **MERN stack**, featuring a user-friendly interface, seamless cart management, and a smooth ordering experience.

## 🛠️ Tech Stack

**Frontend:** React & JavaScript  
**Backend:** Node.js & Express.js  
**Database:** MongoDB  
**Payments:** Stripe  
**Deployment:** Vercel

## ✨ Features

* Browse Food Items
* Filter Food Categories
* Add to Cart & Update Quantities
* User Authentication
* Order Placement & Management
* Online Payment Integration
* Admin Dashboard
* Add & Remove Food Items
* Image Upload Functionality
* Responsive User Interface

## 🎯 What I Learned

Through this project, I explored:

* Building full-stack applications with the **MERN stack**
* Creating reusable UI components with **React**
* Developing RESTful APIs with **Node.js and Express.js**
* Managing application data with **MongoDB**
* Integrating online payment gateways with **Stripe**
* Implementing authentication with **JWT**
* Handling image uploads
* Managing cart state and order workflows
* Building an admin dashboard for food management
* Connecting the frontend and backend through API requests
